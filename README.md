# DarkScale Landing Page

Landing page estática de pré-lançamento do DarkScale.

## Publicar na Vercel
1. Extraia o ZIP.
2. Crie um repositório no GitHub.
3. Envie `index.html`, `style.css`, `script.js` e `vercel.json` para a raiz.
4. Na Vercel, clique em **Add New > Project** e importe o repositório.
5. Framework Preset: **Other**. Não precisa de Build Command.
6. Deploy.
